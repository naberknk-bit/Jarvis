# 🛡️ JARVIS - AI-Powered Local Security & Automation Hub

Welcome to the core repository of **Jarvis** (Project: Ultron Max). This is a specialized, Python-based security system designed for local home defense, system optimization, and remote command execution.

## 🚀 Key Features

- **👁️ Face ID Surveillance:** Real-time facial recognition to distinguish between family, friends, and intruders.
- **🪤 Advanced Honeypot:** Decoy folder traps that trigger instant camera snapshots and Telegram alerts upon unauthorized access.
- **📡 Telegram Command Center:** Full remote control via a secure bot (Screenshots, System Status, Voice Synthesis, and Remote Locking).
- **⚛️ Elemental Power Modes:**
  - **Fluorine (F):** Maximum performance profile for heavy tasks.
  - **Uranium (U):** High-alert security mode with active sensors.
  - **Neon (Ne):** Stealth/Privacy mode with silent fans and hidden processes.
- **🎭 Deception Modules:** Matrix overlay and Guest Mode to simulate system failures and deter unwanted users.

## 🛠️ Tech Stack

- **Language:** Python 3.10+
- **Libraries:** OpenCV, Face_Recognition, Telebot, Cryptography, Psutil.
- **Hardware Integration:** Tapo Security Cameras, Local PC Hardware.
